# BackpackEnhance

[English](README.md)

为 GTNH 整合包提供的背包增强模组。

## 功能特性

- **背包悬浮窗** — 打开箱子、机器等容器界面时显示悬浮窗，可在其中查看并使用背包中的物品。
- **多背包切换** — 以标签页形式显示玩家物品栏中的所有背包，点击标签即可切换。
- **位置记忆** — 悬浮窗可自由拖动，不同 GUI 分别记住各自的位置。
- **SHIFT 快速操作** — 悬浮窗展开时，从容器或玩家物品栏 Shift 点击，会优先放入当前选中标签对应的背包；从悬浮窗 Shift 点击，会优先进入当前打开的箱子或机器槽位。
- **大型背包滚动视口** — 超过六行的背包使用垂直滚动视口。鼠标位于滚动条或空背包槽时，滚轮用于滚动视口；位于有物品的槽位时，滚轮会快速移动该组物品。
- **林业原生行为** — 悬浮窗预览和服务端都会执行林业背包过滤规则。标题栏模式按钮可在可用时切换普通、锁定、接收和再补给模式。
- **快捷键** — 在 GUI 中按 **T**（可在控制设置中改键）最小化或展开悬浮窗。

## 兼容性

支持的背包模组（GTNH 版本）：

- **Adventure Backpack**（`AdventureBackpack2`）— 冒险者背包
- **Minecraft Backpack Mod**（`Minecraft-Backpack-Mod` / Brad 背包）— 普通背包
- **林业**（`ForestryMC`，GTNH fork）— T1/T2 专用背包与 125 槽自然学家背包

仅扫描玩家物品栏中的背包并显示为悬浮窗标签。未安装对应模组时会自动忽略。
