# BackpackEnhance

[English](README.md)

为 GTNH 整合包提供的背包增强模组。

## 功能特性

- **背包悬浮窗** — 打开箱子、机器等容器界面时显示悬浮窗，可在其中查看并使用背包中的物品。
- **创造模式物品栏** — 在创造物品栏的“生存物品栏”标签中显示悬浮窗，切换到其他创造标签时隐藏。
- **多背包切换** — 以标签页形式显示玩家物品栏中的所有背包，点击标签即可切换。
- **位置记忆** — 悬浮窗可自由拖动，不同 GUI 分别记住各自的位置。
- **SHIFT 快速操作** — 悬浮窗展开时，从容器或玩家物品栏 Shift 点击，会优先放入当前选中标签对应的背包；从悬浮窗 Shift 点击，会优先进入当前打开的箱子或机器槽位。
- **大型背包滚动视口** — 超过六行的背包使用垂直滚动视口。鼠标位于有物品的槽位、空槽、槽位间隙或滚动条上时，滚轮统一用于滚动视口。
- **林业原生行为** — 悬浮窗预览和服务端都会执行林业背包过滤规则。标题栏模式按钮可在可用时切换普通、锁定、接收和再补给模式。
- **快捷键** — 在 GUI 中按 **T**（可在控制设置中改键）最小化或展开悬浮窗。
- **AE2 无线终端** — 玩家物品栏中已绑定、有电且处于无线范围内的终端会显示为标签。ME 物品显示汇总数量，支持左右键、Shift 转移、拖动存入、双击收集及数字键取放；服务端执行 AE2 权限检查和终端耗电。
- **无线显示** — 无线标签使用五行视口及小号库存数量文字，关闭并重新打开物品栏界面时恢复上次选中的标签。
- **物品搜索** — 搜索框过滤无线库存；普通背包保留槽位位置，以高亮匹配项、暗化未匹配项显示搜索结果。安装 NEI 时使用 NEI 搜索语法，其他环境按物品名称匹配。NEI 搜索框双击启用的物品栏高亮也作用于悬浮窗槽位。双击悬浮窗搜索框可循环切换到包含匹配物品的背包，并滚动到首个匹配项；无线标签按已加载的库存参与。点击悬浮窗搜索框会释放 NEI 输入焦点。右键清空，Escape 或 Enter 取消输入焦点。

## 兼容性

支持的背包模组（GTNH 版本）：

- **Adventure Backpack**（`AdventureBackpack2`）— 冒险者背包
- **Minecraft Backpack Mod**（`Minecraft-Backpack-Mod` / Brad 背包）— 普通背包
- **林业**（`ForestryMC`，GTNH fork）— T1/T2 专用背包与 125 槽自然学家背包
- **Applied Energistics 2**（`appliedenergistics2`，GTNH fork）— 已注册的无线物品终端，包括兼容的 Wireless Crafting Terminal 物品

仅扫描玩家物品栏中的背包并显示为悬浮窗标签。未安装对应模组时会自动忽略。

### 无线库存同步

服务端每十 tick 检查终端可用性，并在取放前再次检查。只有当前选中且展开的无线标签会订阅 ME 库存更新；首次读取的库存分块发送，后续发送发生变化的物品数量。容器界面之间切换时复用有效的终端连接，重新选中无线标签时刷新库存。关闭悬浮窗会话时释放库存监听。

打开 AE 终端时，连接同一 ME 网络的无线标签会隐藏，并释放对应的悬浮窗库存监听；连接其他网络的标签仍可使用。

无线标签提供已存物品的取放，并支持鼠标下物品的 NEI 配方及用途查询。本版无线集成范围包括物品库存；NEI 配方自动填充、材料和工具借还、ME 自动合成请求、流体及终端视图元件过滤留待后续实现。
