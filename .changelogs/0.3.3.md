## 修复内容

- 修复创造模式下从玩家物品栏取起物品并放入背包侧栏时，物品暂时消失或回到玩家物品栏的问题，涵盖单击 NEI 作弊获取物品后再取起存入侧栏的流程。创造模式原生点击完成后会同步鼠标上的物品。
- 修复侧栏取出的物品放回创造模式玩家物品栏后，服务端仍残留鼠标物品的问题。
- 为侧栏点击和拖放回包增加光标版本校验，避免延迟回包覆盖后续取起、放下或关闭界面后的鼠标状态。存入、取出、模式切换等刷新只更新背包标签页。
- 新增 12 个回归测试，覆盖创造模式光标同步、NEI 获取后的转移、服务端校验、数据包序列化及延迟回包；完整构建通过全部 75 个测试。

### 升级说明

本版本调整了侧栏点击、拖放和状态数据包格式，并新增创造模式光标同步数据包。联机时请将客户端与服务端的 BackpackEnhance 同步升级至 0.3.3。

默认材质随模组内置。Modernity 用户可安装本 Release 附带的 `Modernity-BackpackEnhance-0.3.3.zip`，材质路径与 0.3.2 兼容。

## Fixes

- Fix items temporarily disappearing or returning to the player inventory when picked up from the creative player inventory and placed in the backpack overlay. This includes picking up items obtained by single-clicking NEI in cheat mode. Native creative clicks now synchronize the carried stack after completing their slot updates.
- Fix a carried stack remaining on the server after an item extracted from the overlay is placed in the creative player inventory.
- Add cursor revision checks to overlay click and drag responses so delayed replies preserve later pickup, placement and GUI-close cursor state. Deposit, extract and mode-switch refreshes update backpack tabs only.
- Add 12 regression tests covering creative cursor synchronization, transfers after NEI item acquisition, server-side validation, packet serialization and delayed responses. The full build passes all 75 tests.

### Upgrade notes

This version changes the overlay click, drag and state packet formats and adds a creative cursor synchronization packet. Multiplayer clients and servers must upgrade BackpackEnhance together to 0.3.3.

Default textures are bundled with the mod. Modernity users can install the attached `Modernity-BackpackEnhance-0.3.3.zip`; texture paths remain compatible with 0.3.2.
