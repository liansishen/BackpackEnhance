## 修复内容

- 修复创造模式玩家物品栏中取起适配背包后，侧栏重新扫描时清空鼠标上的背包、导致背包消失的问题。扫描回包只刷新侧栏，背包存取操作继续同步鼠标上的物品。
- 修复选中 Backpack edited for moddednetwork（Brad's Backpack）标签页后，Shift 左键背包本体会将其装入自身并使本体消失的问题。普通、工作台和末影背包的侧栏现在遵循原生槽位的背包禁入规则及配置的物品黑名单。
- 新增 12 个回归测试，覆盖光标同步、背包嵌套限制、禁入物品和普通物品转移。

### 升级说明

本版本调整了侧栏状态数据包格式。联机时请将客户端与服务端的 BackpackEnhance 同步升级至 0.3.2。

默认材质随模组内置。Modernity 用户可安装本 Release 附带的 `Modernity-BackpackEnhance-0.3.2.zip`，材质路径与 0.3.1 兼容。

## Fixes

- Fix supported backpacks disappearing from the cursor after picking them up in the creative player inventory. Overlay rescan responses now refresh tabs without overwriting the carried stack; overlay item actions continue to synchronize it.
- Fix Shift-clicking the selected Backpack edited for moddednetwork (Brad's Backpack) into itself, causing the backpack item to disappear. Ordinary, workbench and ender backpack tabs now enforce native slot nesting restrictions and the configured item blacklist.
- Add 12 regression tests covering cursor synchronization, backpack nesting restrictions, blocked items and ordinary item transfers.

### Upgrade notes

This version changes the overlay-state packet format. Multiplayer clients and servers must upgrade BackpackEnhance together to 0.3.2.

Default textures are bundled with the mod. Modernity users can install the attached `Modernity-BackpackEnhance-0.3.2.zip`; texture paths remain compatible with 0.3.1.
