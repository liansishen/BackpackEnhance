## 更新内容

- 将悬浮窗图集拆分为 29 张独立控件材质，并支持通过资源包配置和重载文字、搜索框及遮罩颜色。
- 展开、翻页和林业背包模式标记改用固定 PNG，保持更换游戏字体后的图标外观稳定。
- 滚动条使用固定大小滑块并常驻显示；无法滚动时显示禁用态。Modernity 配色与创造物品栏保持一致，补齐翻页箭头的悬停效果。
- 默认布局每页显示 6 个标签，标签内物品图标缩小并居中留白；AE 无线终端标签默认显示 6 行。
- 更新 Modernity 适配包封面，保留 Modernity 边框并使用中央 B 按钮；随本次 Release 提供 `Modernity-BackpackEnhance-0.3.1.zip`。

### 材质包兼容性

0.3.1 使用新的独立材质路径，0.3.0 及更早版本的单张 `overlay.png` 需要迁移。默认材质随模组内置；Modernity 用户可将本 Release 的适配包 ZIP 放入游戏 `resourcepacks` 目录并启用。材质制作与迁移规则见仓库的 `resourcepacks/README.md`。

## Changes

- Split the overlay atlas into 29 independently editable component textures, with resource-pack overrides and reload support for text, search and shading colors.
- Replace expand, pagination and Forestry mode glyphs with fixed PNG icons that retain their appearance when game fonts change.
- Keep the fixed-size scrollbar visible, including its disabled state. Match Modernity's creative-inventory scrollbar styling and add distinct pagination hover textures.
- Show six tabs per page in the default layout, with smaller centered item icons. AE wireless tabs now default to six visible rows.
- Refresh the Modernity pack icon with the matching outer frame and a central B button. This release includes `Modernity-BackpackEnhance-0.3.1.zip`.

### Resource-pack compatibility

Version 0.3.1 uses new component texture paths. Packs using the single `overlay.png` from 0.3.0 or earlier need migration. Default textures are bundled with the mod; Modernity users can install the attached adapter ZIP directly in `resourcepacks`. See `resourcepacks/README.md` in the repository for authoring and migration instructions.
